## 👋 Hey, I'm BigBobbleHead

I build tools that let the FC modding community make **their own stadiums**: real crowds, real banners and real atmosphere, without wrestling raw game files by hand.

Everything here is made for **offline, single-player** modding with the FIFA Editor Tool.

---

## 🚀 Featured: FC27 Stadium Builder **v2.0**

> 🎉 **Version 2.0 is here.** It's the biggest update yet.

A full visual stadium editor for FC27. Build, dress and export a stadium in one app, then load it through the FIFA Editor Tool.

| | |
|---|---|
| 🏗️ **Build & edit** | 3D viewport, multi-select, grouped moves, editable collisions |
| 👥 **Crowds** | Crowd generator with walker paths |
| 📸 **Menu photos** | Your own stadium menu images, ready to use |
| 🔁 **FIFA 16 import** | Bring classic stadiums over, with automatic model repair and banner placement |
| 🚩 **Banners kept** | Base stadium banners stay put when you replace a shell |
| 📦 **Export Everything** | One click to package your whole stadium |
| 🌍 **16 languages** | The whole interface is translated |

👉 **[See the full FC27 Stadium Builder page](https://github.com/bigbobbleheadmods/FC27-Stadium-Builder)**
